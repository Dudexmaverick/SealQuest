# 🦭 Seal Quest — A Jornada ao Santuário

### 🌊 Uma pequena foca, um grande oceano e uma missão especial!

**Seal Quest** é um jogo 2D de aventura e conscientização ambiental, desenvolvido em **Swift**, no qual o jogador acompanha uma pequena foca em sua jornada por um oceano ameaçado pela poluição.

Durante a aventura, a personagem precisa desviar de resíduos, coletar peixinhos, superar desafios e avançar pelos níveis até alcançar seu destino: **o Santuário das Focas**, um lugar seguro onde poderá viver em paz.

O projeto combina entretenimento, tecnologia e educação ambiental para incentivar a reflexão sobre a preservação dos oceanos e a proteção da vida marinha.

---

## 🎮 Sobre o jogo

O jogador controla uma pequena foca que precisa atravessar diferentes regiões do oceano.

Durante a jornada, deverá:

- 🦭 Controlar a movimentação da foca.
- 🥤 Desviar de resíduos e obstáculos.
- 🐟 Coletar peixinhos para ganhar pontos.
- ❤️ Preservar suas vidas.
- 🌊 Avançar por níveis progressivamente mais desafiadores.
- 🏝️ Chegar ao Santuário das Focas.

## 🗺️ Fases planejadas

**Nível 1 — Primeiros Mergulhos**

A foca inicia sua jornada, aprende a se movimentar e enfrenta os primeiros resíduos espalhados pelo oceano.

**Nível 2 — Mar de Plástico**

A poluição aumenta, exigindo mais atenção e estratégia para evitar obstáculos.

**Nível 3 — Correntes Perigosas**

A jornada fica mais difícil, com novos desafios e obstáculos.

**Final — O Santuário das Focas**

Após superar os desafios, a personagem finalmente encontra um ambiente seguro, longe da poluição.

## 🚀 Como executar

**Pré-requisitos:** Swift, GTK4 e as dependências do SwiftGtk instalados.

Clone o repositório:

```bash
git clone https://github.com/Dudexmaverick/SealQuest.git
```

Entre na pasta:

```bash
cd SealQuest
```

Compile:

```bash
swift build --jobs 1
```

Execute:

```bash
swift run --jobs 1
```

## 🌱 Impacto ambiental

Seal Quest busca apresentar, de maneira lúdica, os perigos que resíduos descartados inadequadamente representam para os animais marinhos.

A proposta é utilizar jogos digitais como ferramenta de conscientização e educação ambiental.
