# SealQuest 🌊

Jogo de aventura submarina desenvolvido em Swift.

## Sobre o projeto

SealQuest é um protótipo de jogo 2D que combina aventura e conscientização sobre a preservação dos oceanos.

O jogador deve coletar peixes, evitar resíduos marinhos e avançar pelos níveis até chegar ao santuário.

## Funcionalidades

- Movimentação do personagem
- Coleta de peixes
- Obstáculos e colisões
- Sistema de pontuação
- Sistema de vidas
- Progressão de níveis

## Tecnologias

- Swift
- SwiftGtk
- GTK4
- Ubuntu Linux

## Como executar

Instale o Swift e as dependências GTK4 necessárias.

Compile:

    swift build --jobs 1

Execute:

    swift run --jobs 1
